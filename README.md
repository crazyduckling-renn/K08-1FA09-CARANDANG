# Distance Calculator

## Description

This Python program calculates the distance between two points on a coordinate plane. It uses the distance formula and the Python `math` library to calculate the Euclidean distance between the two points.

The program asks the user to enter the x and y coordinates of two points, performs the calculation, and displays the distance rounded to two decimal places.

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the `distance_calculator.py` file in a Python editor or IDE.
4. Run the program.
5. Enter the coordinates requested by the program.

## Input Needed

The program requires four numerical inputs:

* `x1` - x-coordinate of the first point
* `y1` - y-coordinate of the first point
* `x2` - x-coordinate of the second point
* `y2` - y-coordinate of the second point

## Sample Output

```text
Enter x1: 2
Enter y1: 3
Enter x2: 5
Enter y2: 7

The distance between the two points is: 5.00
```
